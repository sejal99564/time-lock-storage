# 🔐 Time-Lock Storage

A full-stack secure file storage web application where files automatically expire after a chosen time.

## 🚀 Features
- JWT Authentication
- File Upload & Secure Download
- Auto Expiry Countdown
- Extend Expiry
- Storage Tracking
- Modern Responsive UI

## 🧱 Tech Stack
Frontend: React + TailwindCSS
Backend: Node.js + Express
Database: MongoDB
Auth: JWT
